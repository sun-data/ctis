Inverting a Synthetic Scene with MART

Reconstructing a spectral cube from four dispersed images with the multiplicative algebraic reconstruction technique

Roy T. Smart

This talk walks through the "Invert a Synthetic Scene with MART" tutorial in the ctis documentation. Every figure is regenerated from the current code each time the docs build.

The inverse problem

A computed tomography imaging spectrograph (CTIS) images the same field through several dispersion directions in a single exposure.

Each pixel mixes position and Doppler velocity, so recovering the cube is a limited-angle tomography problem.

81,920 unknowns: a 64 × 64 × 20 cube in position and velocity
32,768 measurements: 4 channels × 128 × 64 pixels

2.5× more unknowns than measurements

The problem is underdetermined: there are more voxels in the cube than pixels in all four images combined. Any reconstruction has to lean on the algorithm's implicit prior, which for MART is positivity and a multiplicative update from a flat start.

Each channel sums along a tilted line

The test scene summed over y (left) and over x (right). Each line is the set of scene points that land on one pixel: dispersion shifts the image by 0.4″ for every 10 km/s.

The 005 and 185 degree channels disperse along x, so their lines of sight tilt in the x-velocity plane with opposite slopes. The 095 and 275 degree channels do the same along y. Four projection angles is very few for tomography, which is why the reconstruction is hard.

The test scene

Color encodes Doppler velocity; brightness encodes radiance.

  • Eight Gaussian blobs at random positions and Doppler shifts
  • 20″ × 20″ field on a 64 × 64 grid
  • ±500 km/s around 171 Å in 20 velocity bins
  • Uniform background of 1% of the peak
  • Designed by Amy R. Winebarger
The scene is ctis.scenes.gaussians, originally prepared by Amy Winebarger. The tutorial adds a uniform background of 1% of the peak so that no part of the field is empty.

Its average spectrum

A blueshifted and a redshifted component, each about 125 km/s from rest, on a flat background.

This is the spatial average of the cube. Keep it in mind: we will compare the reconstruction's average spectrum against it at the end.

An ideal four-channel CTIS

Channels4, dispersed at 5.64° + 0°, 90°, 180° and 270°
Dispersion10 km/s per pixel (5.70 mÅ per pixel)
Plate scale0.4″ per pixel
Sensor128 × 64 pixels per channel
Exposure20 s with 1 cm² of effective area
NoisePhoton shot noise only

ctis.instruments.IdealInstrument has no point-spread function, distortion or vignetting.

An ideal instrument isolates the inversion problem from the optics; OptikaInstrument adds the real optics later.

What the instrument records

One 20 s exposure. Each channel sees the same blobs, shifted along its dispersion direction in proportion to their velocity.

Compare the blob arrangement between opposite channels: the shifts go in opposite directions, which is what lets MART separate position from velocity.

The MART loop

  1. Start from a flat guess, $\hat{u}_0$.
  2. Predict the images: $d_i = P\,\hat{u}_i$
  3. Score the fit: $\langle \chi_i^2 \rangle = \left\langle \left( \frac{d_i - d}{\sigma_i} \right)^2 \right\rangle$
    Stop when it improves by less than $T = 10^{-3}$.
  4. Correct each channel: $C_i = \left( \frac{P^* d}{P^* d_i} \right)^{\gamma}$
    The learning rate is $\gamma = 2 / N$.
  5. Update: $\hat{u}_{i+1} = \overline{C}_i \, \hat{u}_i$
    $\overline{C}_i$ is the geometric mean over the $N$ channels.

Compared with Parker et al. (2022)

Corrections are computed in scene coordinates, so flux is conserved in both the forward and backward projections.

No contrast-enhancement filter yet.

Multiplicative updates keep every voxel positive.

P is the forward model and P-star the deprojection, which spreads each pixel's signal evenly back along its line of sight. The learning rate gamma tempers each channel's correction before the channels are combined.

Three calls in ctis


instrument = ctis.instruments.IdealInstrument(
    dispersion=dispersion,          # 10 km/s per pixel
    angle=angle,                    # 4 dispersion directions
    plate_scale=0.4 * u.arcsec / u.pix,
    ...,
)
images = instrument.image(scene)    # forward model + shot noise

mart = ctis.inverters.MartInverter(instrument=instrument)
inversion = mart(images)            # reconstruct the cube

inversion.plot_moments(scene, axis="wavelength")

Reconstruction, iteration by iteration

Each frame is one MART update. The label gives $\langle \chi^2 \rangle$ averaged over the four channels.

The blobs appear within a few iterations; later iterations sharpen them and also build up the speckled background noise.

Convergence

$\langle \chi^2 \rangle$ ends at 0.33, well below the noise level of 1 (dashed), so the later iterations are fitting noise. MART stopped after 22 updates, when $\langle \chi^2 \rangle$ improved by less than $10^{-3}$.

With more unknowns than measurements, MART can always reduce chi-squared further by fitting the noise. Where to stop is a real choice; the current rule stops only when chi-squared stops improving. The signal-correlated residual peaks early, while the blobs are still forming, then falls as structure moves out of the residual.

The average spectrum, recovered

The peaks come back 17% and 14% low, and the dip between them 65% high: MART spreads intensity into the line wings.

This wing inflation is consistent with the crossing-streak ("plaid") artifact that Parker et al. 2022 suppress with smoothing. An optional smoothness regularization is in review and will be judged on ESIS data.

Line moments, pixel by pixel

True against reconstructed radiance, Doppler shift (median velocity) and line width (interquartile range) for every pixel. The dashed line is perfect recovery.

Radiance is recovered best. The Doppler shift is the hardest moment; the vertical band at zero true velocity is the background, which has no Doppler shift.
